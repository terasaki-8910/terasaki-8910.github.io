# /visualization/ のページの決まり（このページの作業だけに効く）

本人の意見（2026-10-15）から決まった作り方。言われなくても守る。残りの作業は `.claude/visualization-tasks.md`。

## 構成
- タブで1つずつ（変換・投影・補間・IK / 剛体と衝突 / 布 / 流体）。全部を一度に出さない
- 各タブは「全体のシミュレーション → 計算ごとの小さなシミュレーション（段階）→ 組み合わせると全体になる」。式を並べるだけにしない。目標は「これを見ただけで理解できる」
- 段階の中は「説明 → シミュレーション → 式 → 記号の意味（開閉）→ 実装を見る」
- 説明は高校数学の言葉で、いちばん単純な場合から積み上げる（例：1本のバネ → 単振動 → 時間の進め方 → 減衰 → 安定の条件 → 鎖 → 網）

## 見た目と操作
- 横長の PC はシミュレーションが左、変数のバーが右。縦長とスマホは上にシミュレーション、下にバー。本物の画面幅（375・768・820×1180・1180×820・1024・1280・1440）で確かめる
- 全体のシミュレーションには凡例：x・y の軸と目盛り（単位つき）、時刻 t と Δt、重力 g の矢印、風など動きに効く量
- どのシミュレーションも手で動かせる（つかめる物の上で grab、つかんでいる間 grabbing）。動かした結果にスライダーと数（行列など）が追従する
- 色はトークンだけ（`--color-*`・`--lane-*`・`--diff-*`）。文字 4.5:1、図形 3:1 以上。動きを減らす設定では止まった状態から始め、画面外とタブの外は止める
- サイト自身の慣習に合わせる（一般的な Web の慣習ではなく）。ページの登録・フォントのサブセットの手順はサイトの README と既存のページに従う

## 中身
- 計算は `src/utils/vis/`（DOM に触れない純関数、テスト `node --test "tests/vis/*.test.js" "tests/vis-page/*.test.js"`）だけを使い、ページの中で式を書き直さない
- 載せないもの：授業のスライドの画像・文言、文字起こし、手書き、大学名。式は一般形、出典は元の論文・教科書（確かなものだけ）
- 新しい意見は、このファイルと `.claude/visualization-tasks.md` に書いてから直す

## 進め方
- 見た目の案を2〜3個作らない（好みはここに書いてある）。1案で作り、意見で直す
- 作業は `feat/visualization-<中身>` のブランチで。main への push は本番の公開なので、本人に確かめてから。公開の前に `docs/` を組み直してコミット（Steam の自動コミットとぶつからないよう、main に合わせてから組む）
