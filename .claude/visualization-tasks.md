## 共有部品の直しの候補（2026-10-26 の続きのページのキーボード・読み上げの見直しで見つけたもの。両ページに効く。順番は本人と決める）
- SimCanvas：キーで操作できる canvas も role="img" のまま。スクリーンリーダーのブラウズモードでは矢印キーが canvas に届かないおそれがある（未検証）。tabIndex があるときは role="application" と aria-roledescription にし、選んでいる物と値を role="status" の見えない領域で知らせる（sim ごとに知らせる文が要る）
- useCanvas：redraw が draw を ctx.save()・restore() で囲んでいないので、draw が変えた textAlign などが次のフレームに残る。続きのページは各 draw で戻している。共有側で囲むなら、既存ページの文字の位置が変わらないかを画面で確かめる
- .vis-canvas の touch-action: none：操作する canvas の上では、スマホでページをスクロールできない（絵の高さ 220〜300px）。つかめる物の上だけ止める形（canGrab）にできるか、iOS で確かめてから
