取り組んでいる研究

データセットごとにスキーマが異なる Linked Open Data で、SPARQL クエリを書き始めるための支援を研究しています。卒業研究ではクエリ緩和による別のデータセットへの再利用を、現在は大規模言語モデルによるクエリ例の提示を扱っています。

  • Toward Portable SPARQL Queries Across Linked Open Data: A Query Relaxation Approach to Cross-Dataset Rewriting（Masato Hinooka, Mitsuharu Nagamori。20th International Conference on Metadata and Semantics Research（MTSR 2026）、採択、査読有り）
  • 未知のLODデータセットに対する問い合わせのための知識獲得支援手法の検討（日野岡雅人, 永森光晴, 三原鉄也。人工知能学会 第69回セマンティックウェブとオントロジー研究会）
  • クエリの再利用性向上を目的とした異なるLODデータセット間におけるQuery Relaxation に基づくSPARQL 変換手法（日野岡雅人, 永森光晴, 三原鉄也。人工知能学会 第68回セマンティックウェブとオントロジー研究会）
  • 表面プラズモン共鳴を用いた蛍光増強の基礎的検討（寺﨑雅人, 内海淳志。電気学会関西支部 第30回高専研究発表会）
